# First vehicle: Octavia vRS reference

User selected: Skoda Octavia vRS.
Working assumption: first-generation liftback (not estate or a newer generation).
Visual direction: gritty, simplified realism.

## Reference and setting

The first Octavia RS arrived with the 2000 facelift, with a 1.8-litre turbo engine rated at 180 hp.
This is later than the game's current mid-1990s setting.
Use it as a prototype reference now; the user has not yet approved changing the story era.
Do not confuse the road-going RS with an Octavia WRC competition car.

Sources and reference photos:
- https://www.skoda-motorsport.com/en/skoda-octavia-rs-evolution-of-speed/
- https://www.skoda-storyboard.com/en/skoda-world/skoda-octavia-rs-how-it-has-evolved/
- https://www.skoda-storyboard.com/en/skoda-world/skoda-octavia-25-years-at-the-top/

## Initial blockout

Use an approximately 4.5 m long, 1.75 m wide liftback as a provisional modelling envelope.
The first-generation liftback wheelbase reference is 2.512 m (Skoda's historical overview).
Envelope dimensions are rounded art targets, not exact RS specifications.
Confirm wheel diameter, track widths, mass and centre of gravity before vehicle tuning.

Start with a body shell and four separate wheels. Include enough cabin space for driver
and co-driver and an accessible rear cargo area. Refine shape after driving is proven.
Use the functioning Chaos example vehicle temporarily if asset integration would delay testing.

## Amateur rally treatment (proposed)

- Worn paint, one mismatched panel and restrained homemade rally markings.
- Gravel tyres and increased clearance relative to the road-car reference.
- Two seats, basic roll cage, analog dashboard and a simple co-driver note board.
- A spare wheel and tools stored in the boot.
- Readable radiator and suspension locations for the prototype repairs.

These are game-design proposals, not stock Octavia specifications.

## Model requirements

- Editable source preferred, with FBX export.
- Separate wheel meshes with pivots at wheel centres.
- Separate bonnet and tailgate; front doors ready for later interaction.
- Basic visible interior for both occupants.
- Simple radiator and suspension placeholders; detailed engine internals can wait.
- Keep textures modest initially (1K/2K); test the complete scene on the development GPU.
- Export in a documented scale; Unreal assembly uses centimetres, X forward and Z up.
- Asset purchase is not approved or needed at this stage.
